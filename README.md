## Flujo de trabajo del equipo

Ya que la idea es que trabajemos en un solo proyecto en Godot, se eliminaron los proyectos que se habían creado por separado. A partir de ahora, la dinámica es la siguiente:

### 1. Clonar el repositorio
Cada integrante debe clonar el proyecto desde **GitHub Desktop** (no crear un proyecto nuevo en Godot).

1. Instala GitHub Desktop desde [desktop.github.com](https://desktop.github.com).
2. **File → Clone Repository** → selecciona `Bomberman-2D-Godot`.
3. Elige la carpeta local donde se guardará.

### 2. Abrir el proyecto en Godot
1. Abre Godot → **Import** (no "New Project").
2. Selecciona el archivo `project.godot` dentro de la carpeta clonada.

### 3. Crear tu branch
Antes de hacer cualquier cambio, crea tu propia branch desde `main`.

**Nomenclatura:** `nombre-díadelmes`

Ejemplos:
- `isa-03`
- `david-03`
- `danna-03`
- `gaby-03`
- `yudy-03`

En GitHub Desktop: **Branch → New Branch** → escribe el nombre.

### 4. Trabajar y guardar avances
1. Guarda tus archivos en la carpeta correspondiente (`scenes/tu-elemento/`, `scripts/tu-elemento/`).
2. En GitHub Desktop, escribe un resumen del cambio y haz **Commit to [tu-branch]**.
3. Haz **Push origin** para subirlo a GitHub.

### 5. Pull Request
1. Cuando tu parte esté lista, abre un **Pull Request** de tu branch hacia `main`.
2. El PR queda esperando revisión — **Isa lo aprueba** antes de que se haga merge a `main`.

### 6. Mantente actualizado
Antes de empezar a trabajar, haz **Pull origin** desde `main` para traer los últimos cambios ya fusionados.

**Regla SUPERMEGA IMPORTANTE:** nunca trabajar directo sobre `main` — siempre crear una branch primero.
